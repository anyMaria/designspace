3 · Word fields (Type, Vibe, Movement, Tags)

One combobox for every word field (Details, Triage, editing several items). Existing words always come first; making a new word is the last row and never the default when a match exists, so near-duplicates can't happen by accident. Arrow keys move, Enter picks the highlighted row, Esc closes the list (a second Esc leaves the field).

7 · Font families and type collections

One card per family. In Details, "On the card" sets the style (or a weight for variable fonts), the text size and the text. A type collection groups families like a palette groups colours, but every row is still its own family: it can be classified, opened and connected, and lines attach to its row.

8 · Resizing, cropping, favourites, List tiles

Eight handles. Corners keep the proportions (hold Shift for free); sides change them. Hold Alt to resize from the centre. Pictures never stretch: when the proportions change, the card becomes a window onto the picture (a crop), and "Adjust crop" moves the picture inside it.
